# SD12 Graduation Album 2013

성동고등학교 제12회동창회 졸업 앨범 (2013년판)

## 📋 Overview

This is a digital graduation album showcasing memories from Seongdong High School's 12th alumni association. The project includes multiple photo albums from various events and activities.

## 🗂️ Project Structure

```
Album/
├── index.html                      # Main entry point
├── README.md                       # This file
├── css/
│   └── sdalbum.css                # Main stylesheet
├── images/                         # Image assets
│   ├── sd12.ico
│   └── sd12_gold200.png
├── albums/
│   ├── graduation/                # 졸업 앨범
│   │   └── index.htm
│   ├── meetings/                  # 동창회앨범
│   │   └── index.htm
│   ├── climbing-club/             # 산악회앨범
│   │   └── index.htm
│   └── events/                    # 이벤트앨범
│       └── index.htm
└── tools/
    └── album-launcher.exe         # Album launcher executable
```

## 🚀 Getting Started

1. **Online Access**: Visit the [GitHub Pages site](https://sd12-63.github.io/Album/)
2. **Local Use**: Open `index.html` in a web browser
3. **Executable**: Run `tools/album-launcher.exe` for standalone access

## 📂 Album Categories

- **졸업 앨범** (Graduation Album) - Graduation ceremony and class photos
- **동창회앨범** (Alumni Meeting Album) - Reunion and alumni events
- **산악회앨범** (Climbing Club Album) - Mountain climbing activities
- **이벤트앨범** (Event Album) - Special events and activities
